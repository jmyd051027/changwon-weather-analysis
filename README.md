# 📊 창원시 날씨 시계열 분석 프로젝트

## 📝 프로젝트 소개
본 프로젝트는 기상청 공공데이터를 활용하여 **2026년 창원시의 날씨 시계열 데이터**를 분석하고, 기후 변화의 흐름과 특징을 파악하기 위해 진행된 데이터 분석 프로젝트입니다. 

단순한 데이터 시각화를 넘어, 데이터 속에서 유의미한 패턴을 발견하고 가설을 세워 해석하는 **데이터 기반 의사결정 역량**을 기르는 것을 목표로 하였습니다.

## 🎯 주요 분석 질문
본 분석은 다음 3가지 핵심 질문을 바탕으로 진행되었습니다.
1. 창원시의 월별 평균 기온은 어떻게 변화하는가?
2. 창원시의 월별 평균 일교차는 어느 달이 가장 큰가?
3. 창원시의 월별 강수량은 어떻게 분포되어 있는가?

## 🛠️ 기술 스택 (Tech Stack)
- **Language:** Python 3.10+
- **Environment:** Jupyter Notebook
- **Libraries:** 
  - `pandas` (데이터 전처리 및 시계열 집계)
  - `matplotlib` (데이터 시각화)

## 📁 파일 구조 (Repository Structure)
- `analysis.ipynb` : 데이터 전처리, 시계열 분석 및 시각화가 포함된 메인 파이썬 코드
- `REPORT.md` : 분석 목적, 시각화 결과, 인사이트 및 결론이 담긴 **최종 분석 보고서**
- `*.png` : 보고서에 사용된 시각화 그래프 이미지 파일들

## 🚀 실행 방법 (How to Run)
1. 이 저장소를 Clone 하거나 다운로드합니다.
2. 필수 라이브러리를 설치합니다. (`pip install pandas matplotlib`)
3. Jupyter Notebook 환경에서 `analysis.ipynb` 파일을 엽니다.
4. 상단 메뉴에서 `Run All`을 클릭하여 위에서부터 순서대로 코드를 실행합니다.
